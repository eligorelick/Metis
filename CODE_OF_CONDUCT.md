# Code of conduct

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Participants are expected to follow its standards in project spaces and when representing the project.

Report concerns privately through [GitHub's private advisory form](https://github.com/eligorelick/Metis/security/advisories/new) or a private message to the repository owner through GitHub. Do not post sensitive reports in public issues. The repository owner reviews reports and applies the Covenant's enforcement guidelines.
